100% Local Home Network · Zero Cloud · Free

Simple, private parental control for Windows.

Manage screen time, bedtime, apps, and family DNS across your home network — without cloud accounts, subscriptions, or spying.

Install on the Parent PC. Manage screen time, bedtime, app rules, and pair Child PCs over your home Wi-Fi/LAN.

Download Vylos-Parent.msi
Need the Child PC installer? Download Vylos-Child.msi → v1.1.1 · Windows 10/11
Step 1
Install Parent Edition
Run Vylos-Parent.msi on your PC, set your password, and create a pairing code.
Step 2
Pair Child PC
Run Vylos-Child.msi on your child’s PC and enter the 8-digit pairing code.
Step 3
Protected Offline & Online
Rules stay active on the Child PC even when the Parent computer is turned off.
Screen Time & Bedtime
Daily weekday/weekend limits, scheduled hours, break reminders, and one-click bonus time.
App & Game Limits
Block specific games or restrict them to allowed afternoon hours without touching system files.
Family DNS (1.1.1.3)
One-click Cloudflare Family DNS to block malware and adult domains plus custom blocklists.
Tamper-Protected
Protected Windows service. Children cannot uninstall Vylos or install the Parent Edition.
