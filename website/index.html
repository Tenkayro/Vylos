    Set up across your home network in 3 minutes

    No router changes and no cloud registration — simply install the respective MSI on each computer and pair via a one-time code.

    Step 1 · Parent PC
    Install Vylos-Parent.msi

    Install the Parent Edition on your own Windows PC. Set your Parent Master Password (hashed locally with Argon2id) and generate an 8-character one-time pairing code under Devices.

    Step 2 · Child PC (By Parent)
    Install Vylos-Child.msi & Pair

    Run Vylos-Child.msi on your child’s computer. A parent sets the local protection password, selects the auto-discovered Parent PC on LAN, and enters the one-time pairing code.

    Step 3 · Autonomous Enforcement
    Rules enforced locally — even offline

    Daily time limits, bedtime windows, application rules, and Cloudflare Family DNS are stored locally on the Child PC and enforced by the hardened VylosService background service.

    Why two dedicated installers (Parent & Child)?

    Built from a single open-source codebase, separated into two editions for clarity and multi-layered tamper protection.

    Parent Edition (Vylos-Parent.msi) For Parents

    Provides the full management dashboard. On any computer where Vylos-Child is already active, installing or launching Vylos-Parent is automatically blocked at the Windows Installer, database, and process levels.

    Child Edition (Vylos-Child.msi) For Child PCs

    Compiled exclusively for Child Mode. Displays remaining screen time and active family rules transparently in the System Tray while preventing rule changes or uninstallation without the Parent Password.

    Everything your family needs

    Designed for parents who want reliable boundaries without invasive cloud telemetry.

    Screen Time & Bedtime

    Separate weekday and weekend daily limits, per-day allowed time windows, overnight bedtime locks, break reminders, and instant +15m/+30m bonus time from the Parent PC.

    Application & Game Control

    Automatically scans installed software, highlights newly installed applications, and lets you block or schedule specific executables — while permanently guarding critical Windows processes.

    Family DNS & Domain Filter

    One-click Cloudflare Family DNS (1.1.1.3 / IPv6) to filter malware and adult content, plus custom domain blocklists and allowlists.

    Transparent, Never Covert

    No keylogging, no secret screenshots, and no webcam or microphone snooping. Children always see their remaining time and active rules clearly.

    Modern Cryptography

    TLS 1.3 with SHA-256 certificate pinning over LAN, mutual Ed25519 request signing, Argon2id password hashing, and Windows DPAPI + XChaCha20-Poly1305 local encryption.

    Built-in Auto-Updater

    Checks GitHub Releases for new versions, verifies SHA-256 checksums, and updates both Parent and Child MSI installations automatically.
